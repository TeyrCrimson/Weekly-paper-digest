# Long-wave Infrared Polarimetric Remote Sensing Image Fusion for Vehicle Detection

**Authors:** Wenjuan Zhang, Xiangrui Peng, Zhen Li, Caimeng Yi, Xuesong Ma, Jianwei Wang, Jie Pan

**arXiv:** [2610.27018](https://arxiv.org/abs/2610.27018)

**Categories:** cs.CV

**Submitted:** 2026-10-19

**Relevance:** 7/10 — matched: Onboard object detection from a moving UAV

---

## TL;DR
This paper proposes a Mamba (state-space model) based fusion network for long-wave infrared intensity (S0) and polarization (DoLP) remote sensing images, using physics-derived priors to suppress polarization noise while preserving weak target signals. It also releases a new airborne dataset, AIR-LWIR-Pol (1,901 registered image pairs), and shows the fused images improve downstream YOLO11-based vehicle detection (mAP50 55.0%, mAP50-95 29.4%) over using intensity alone. The core claims rest on besting 8 fusion baselines on 4 of 6 image-quality metrics and 3 of 4 detection metrics on this single self-collected dataset.

## First-principles breakdown

**The underlying physical problem.** A thermal (long-wave infrared, LWIR) camera measures how much heat an object radiates — this is "intensity" (S0). Problem: when a vehicle and the road around it are near the same temperature, they look nearly identical in S0, so detection fails. Polarization imaging adds a second channel: light reflected/emitted off smooth man-made surfaces (like metal vehicle bodies) tends to be partially linearly polarized, while rough natural backgrounds (soil, vegetation) are not. "Degree of Linear Polarization" (DoLP) is a 0-1 ratio describing how polarized the light from each pixel is, computed from four images taken at polarizer orientations 0°, 45°, 90°, 135° (combined into Stokes parameters S0, S1, S2; DoLP = sqrt(S1²+S2²)/S0). So DoLP can reveal a vehicle's metal edges even when its temperature matches the background. The idea: fuse S0 (good overall scene structure) and DoLP (good vehicle contrast) into one image that's better for both human viewing and automated detection.

**Why this is hard.** DoLP signals are physically weak in LWIR and noisy — some noise pixels have spuriously high DoLP ("isolated high responses") that look like strong signal but aren't structurally meaningful, while some real-but-faint vehicle edges have low DoLP. Naively trusting "high DoLP = real signal" either amplifies noise or, if you smooth away noise, erases the faint real signal too. Prior fusion networks (CNN/GAN/Transformer-based) learn a generic mapping between modalities but have no explicit model of *when* a DoLP pixel is physically trustworthy, so they either hallucinate noise or over-suppress weak-but-real polarization detail.

**Why Mamba instead of Transformer/CNN.** CNNs only see local neighborhoods (limited receptive field) so can't relate distant parts of a large aerial image. Transformers can model any-pixel-to-any-pixel relationships via self-attention, but the compute/memory cost scales roughly quadratically with image size (number of pixels) — expensive for high-resolution remote sensing images. State Space Models (Mamba) process a sequence of pixels through a recurrent-like update whose cost grows roughly linearly with sequence length, so they can approximate full-image long-range interaction much more cheaply. The catch: Mamba processes pixels as a 1D sequence, so you must choose an order (a "scan direction") to unroll the 2D image into — and real-world structures (roads, vehicle edges) run in arbitrary directions, not just along rows/columns.

**The method's pipeline, step by step:**
1. **Dual-branch encoder (LLRR, borrowed from prior work):** S0 and DoLP each go through a separate low-rank/sparse decomposition-inspired encoder (motivated by the observation that S0 has smooth, low-rank backgrounds like roads/buildings, while DoLP has sparse, localized vehicle signals) producing feature maps F_S0 and F_DoLP.
2. **Physics-guided Polarization Prior Enhancement Module (PPREM):** builds a per-pixel "trust map" (Guide, values 0-1) of where DoLP is reliable. Two branches feed it:
   - *Polarization Response Branch*: computes F_p = S0 ⊙ DoLP (element-wise product). This is physically motivated — under ideal Stokes-vector theory, S0×DoLP equals the amplitude of the linearly-polarized component (PI), a physically meaningful quantity. Multiplying by S0 naturally suppresses DoLP noise in low-intensity regions (no radiative support) while keeping signal where there's genuine thermal emission.
   - *Spatial Structural Consistency Branch*: a small conv+pooling block applied to DoLP features to detect "is this response spatially coherent (an edge/region) rather than an isolated random spike?"
   - These two outputs are concatenated, convolved, and passed through sigmoid to get the guidance map G — essentially "how much to trust DoLP here."
3. **Multidirectional Cross-Mamba fusion:** standard image-Mamba variants scan pixels only horizontally/vertically. This paper adds two diagonal scan orders (and reverses each of the 4 directions, giving 8 total scan paths) so the sequential state-update can propagate information along any of 4 principal orientations, better matching arbitrarily-oriented roads/vehicle contours. At each of several interaction stages, S0 features and DoLP features are each updated by their own Mamba block (modulated by guidance G), then merged by the 8-direction scan module, and the merged features are fed back to refine each branch again (repeated ~3 times) before final fusion.
4. **Decoder** reconstructs the final fused image from the fused features.
5. **Loss functions** (no ground-truth fused image exists, so these are proxy objectives):
   - *Guided multi-window SSIM loss*: at each pixel, blend structural-similarity constraints to S0 (weight 1-G) and to DoLP (weight G) — trust map decides which source's structure the fused pixel should mimic, computed at 5 different window sizes to capture both fine and coarse structures.
   - *Reconstruction loss*: an auxiliary autoencoder constraint forcing each branch's encoder-decoder to still recover its own input, preventing feature collapse.
   - *Auxiliary intensity reconstruction loss*: uses the decoded S0, DoLP and polarization-angle outputs to simulate three virtual polarizer measurements and check they recombine to the original S0 — a physics-consistency sanity check.
   - *Relative lower-bound loss for polarization saliency*: rather than forcing the fused pixel to exactly equal max(S0,DoLP) everywhere (too rigid, since S0 and DoLP have different units/scales), it only penalizes fused pixels that fall *below* the polarization-saliency proxy P=S0×DoLP, and only at pixels that violate this bound, normalized by P itself (so bright regions don't dominate the loss).

**Dataset construction:** a custom airborne division-of-aperture LWIR polarimeter (captures all 4 polarizer angles simultaneously via separate sub-apertures) flew over Yingkou, China, across 5 scene types. Images went through: flight-line sorting, sharpness-based frame selection, manual quality review, flat-field (nonuniformity) correction using water-surface references, inter-channel geometric registration, and Stokes/DoLP computation — yielding 1,901 registered S0-DoLP pairs, split 1,515 train / 386 test, with manually annotated oriented bounding boxes for vehicles in the test set.

## Key insights

- **Claimed and evidence-supported**: Using the physically-motivated product S0×DoLP as both a feature (PPREM) and a loss target (lower-bound loss) is a concrete, well-reasoned way to inject domain physics into a learned fusion pipeline, rather than relying purely on generic pixel losses (L1/MSE/SSIM). The qualitative figure (Fig. 8) showing F_p has much less noise than raw DoLP while keeping vehicle signal is a believable illustration of the mechanism working as intended.
- **Claimed and evidence-supported (for this dataset)**: The 8-direction (bidirectional × 4 orientations) Mamba scanning is a reasonable architectural fix for the mismatch between Mamba's inherently 1D sequential scanning and 2D scenes with diagonal structures (roads, oblique vehicle orientations); the method wins on 4/6 fusion metrics and 3/4 detection metrics against 8 baselines on the authors' own test set.
- **Claimed contribution, not independently validated**: that this specific combination of priors + loss terms + scan directions is responsible for the gains — no ablation study isolating PPREM, the lower-bound loss, or the diagonal scans individually is presented in the given text, so it's unclear how much each component actually contributes versus the baseline architecture.
- **Genuinely new resource**: AIR-LWIR-Pol is, as far as the text indicates, a new, carefully registered airborne LWIR polarimetric dataset with vehicle annotations — useful to the field independent of the specific model's merits, assuming the data is released.
- **Downstream task validation**: evaluating fusion quality via actual YOLO11 detection performance (not just fusion metrics like SSIM/EN) is a stronger, more practically meaningful validation than typical fusion papers that stop at image-quality metrics.
- **Honest limitation self-reported in results**: the method does not win on recall (ranks below S0 alone and several baselines) — the authors report this transparently rather than only touting their wins, which is a point in favor of the paper's reporting honesty, though it also means the "fusion helps" story is incomplete (precision/mAP up, recall down vs. raw S0).

## Caveats — stated and inferred

- **Single dataset, self-collected, used for both training and all evaluation** (inferred): all fusion-metric and detection results are reported only on the authors' own AIR-LWIR-Pol test split (386 images from one flight campaign, one region, one season/day). No cross-dataset or cross-sensor generalization test is shown. The conclusion explicitly lists "cross-scene generalization" as future work (stated), which confirms generalization was not tested.
- **No ablation study presented in the text** (inferred): despite introducing four distinct novel components (PPREM, 8-direction Cross-Mamba, SSIM prior-weighting, relative lower-bound loss), the paper does not show results with each component removed, so it's impossible to verify from this text which parts actually drive the reported gains versus could be dropped.
- **Mixed/marginal metric wins** (stated): the proposed method loses to PIPFNet on MI and NIMA (by small margins), and the SSIM improvement over the second-best (MSPFusion) is only 0.0039 — the authors themselves call several of these differences small, which weakens the "outperforms on four metrics" headline claim somewhat.
- **Recall regression** (stated): fused images achieve lower recall (0.516) than raw S0 alone (0.576) and several baseline fusion methods (RFN-Nest 0.562, MSPFusion 0.541, PIPFNet 0.529) — the fusion method trades recall for precision, which is a real cost not emphasized in the abstract (abstract only cites mAP improvements).
- **High inference cost** (stated): the method requires 3.794s per image, the second-slowest of all 9 methods compared (only SFMFusion is slower), which the authors acknowledge indicates "substantial inference overhead in the current implementation" — a practical deployment concern for real-time aerial surveillance.
- **No statistical significance / variance reporting** (inferred): all metrics are reported as single point values with no error bars, repeated runs, or confidence intervals, so it's unclear whether the reported differences (e.g., the 0.0039 SSIM gap) are meaningful or within noise.
- **DoLP-to-fused-image physical interpretation is an approximation** (stated): the authors note P=S0×DoLP is only exactly equal to the polarized amplitude PI "under ideal conditions with radiometric calibration," and that in their actual pipeline (normalized/grayscale-mapped images) P is merely a "polarization-saliency proxy," not a true physical quantity — a stated approximation that somewhat softens the "physics-inspired" framing.
- **Detection backbone not varied** (inferred): downstream evaluation uses only one detector (YOLO11s-OBB) with one config; whether the fusion benefit holds across other detector architectures is not addressed in the paper.
- **Weak target scenario (dense scene) still struggles** (stated): in the denser vehicle scene (Fig. 14b), the authors note "missed detections and imperfect localization persist," and precision/F1 in that scene (67.6%/59.9%) is much lower than in the sparser scene (94%/86%), indicating the method's benefit is scene-density-dependent.
- **Baselines' vintage not addressed in the paper**: the text does not specify publication years for most comparison methods (RFN-Nest, GANMcC, GAN-FM, etc.) beyond citation numbers, so whether these represent current state-of-the-art or somewhat dated baselines is not addressed in the paper.
