# A Unified Evaluation Framework of Physical Adversarial Robustness in the Edge VLM Era

**Authors:** Eric Liang, Alan Luo, Kaiwen Yuan

**arXiv:** [2610.29196](https://arxiv.org/abs/2610.29196)

**Categories:** cs.CV, cs.CR, cs.LG

**Submitted:** 2026-10-21

**Relevance:** 6/10 — matched: Onboard object detection from a moving UAV

---

## TL;DR
This paper benchmarks whether compact, edge-deployable Vision-Language Models (VLMs) that do visual grounding (text → bounding box) are as vulnerable to physical adversarial patches as traditional object detectors, since both are increasingly used to localize people in safety-critical systems. Using a new "conditional attack success rate" (cASR) metric that controls for occlusion, and a three-way failure taxonomy (omission, substitution, displacement), they find VLMs can be just as vulnerable as detectors, and that *how* a model fails is driven by its output format (whether it "gates" box emission on detection confidence) rather than its architecture family. Critically, under distribution shift (driving footage vs. training images), some VLMs that used to fail "safely" (visibly, by omission) instead start failing invisibly (confident-but-wrong boxes), which the authors argue makes a naive VLM-for-detector swap potentially *more* dangerous in deployment.

## First-principles breakdown

**The underlying problem.** A classic object detector (like YOLO) looks at an image and outputs a list of boxes, each with a confidence score, for objects it recognizes from a fixed label set. A grounding VLM instead takes a natural-language prompt (e.g., "find the person") and generates a bounding box as part of its text output, often with no confidence score at all — it just commits to an answer. Because VLMs are getting small enough to run on edge devices (phones, robots, cameras), people are starting to swap them in for detectors in real pipelines (e.g., robots that act on "the box around the person"). The safety question: if someone wears a physical, printed-texture adversarial patch (a well-studied attack against detectors — see Thys et al.'s "Fooling automated surveillance cameras"), does a VLM resist it the same way, worse, or differently than a detector would?

**Why comparing them head-to-head is hard.** Detectors output many candidate boxes with scores; you threshold on confidence. VLMs output exactly one box as free-form or structured text, with no confidence knob. A naive "attack success rate" (did detection fail?) is contaminated by two confounds: (1) a gray patch of the same size, with no adversarial content, will *also* sometimes cause failures just by physically occluding part of the person — that's not an adversarial effect, it's an occlusion effect; (2) different models have different baseline localization accuracy, so comparing raw failure rates conflates "this model is bad at the task" with "this model is vulnerable to the attack."

**Their fix — conditional ASR (cASR).** For each model, they first check which images it *still* localizes correctly when a neutral gray square (same size/position as the patch) is placed on the person — call this the "gray-control set" G. Then, within G only, they measure what fraction of those cases the actual adversarial patch breaks. This isolates the adversarial effect from both occlusion artifacts and baseline accuracy differences — a fairer apples-to-apples metric across architecturally different model families.

**Training the attacks.** For each of 11 models (6 detectors — closed-set like YOLO11s/YOLO26s/RT-DETRv2, open-vocabulary like YOLO-World/GroundingDINO — and 5 compact VLMs ≤4B params: InternVL3-2B, PaliGemma 2-3B, Qwen3-VL-2B, MiniCPM-V 4.6, LFM2.5-VL-3B), they train a separate white-box adversarial patch (a 160×160 printable texture, scaled to half the person's bounding-box size and placed on the torso). The patch is optimized by gradient descent to minimize a loss that suppresses that model's own internal detection signal: for closed-set detectors, drive down the person-class confidence score; for open-vocab detectors, drive down the image-region/"person"-text similarity; for VLMs, drive down the model's output likelihood of producing the box tokens for the person. Two auxiliary loss terms (non-printability loss, total-variation loss) keep the patch realistic/printable and smooth, so it's a plausible "adversarial T-shirt" rather than noise. They also apply Expectation-Over-Transformation (random rotation ±20°, brightness jitter ±10%) during training so the patch is robust to minor real-world-like variation — though note, importantly, all evaluation is still done digitally (patch composited into images), not photographed in the real world.

**Failure taxonomy.** Given a predicted box (or lack thereof), they classify each adversarial failure into exactly one of three exhaustive, mutually exclusive categories: *omission* (model outputs no valid box — e.g., "there is no person"), *substitution* (model outputs a box that overlaps the patch itself, i.e., it mistakes the patch for the person), and *displacement* (model outputs a box that overlaps neither the person nor the patch — just wrong). This partition matters because only omission is detectable downstream — a system that gets "no box" knows something failed. Substitution and displacement both silently return a confident, well-formed, wrong box, which a downstream planner/safety system has no way to distinguish from a correct detection.

**Key mechanistic finding — "gated" vs. "free-text" output grammar.** Models like PaliGemma 2-3B and InternVL3-2B emit a special token that gates whether a box is produced at all (akin to a detector's confidence threshold) — suppressing the underlying likelihood can make that gate never fire, producing omission. Models like Qwen3-VL-2B, LFM2.5-VL-3B, and MiniCPM-V 4.6 always write out coordinate text regardless of whether the target is actually visible (no such gate), so the attack can't delete the box — it can only nudge the coordinates, producing displacement/substitution instead of omission. This output-format property, not whether the model is a detector vs. VLM vs. its parameter count, predicts the failure-mode split.

## Key insights

- **Genuinely new**: the cASR metric itself — a principled way to strip occlusion and baseline-accuracy confounds out of adversarial patch evaluation, enabling fair cross-architecture comparison (detector vs. VLM) on a shared predicate ("does a box land on the target"). This methodological contribution looks solid and is the paper's main lasting artifact.
- **Genuinely new**: the omission/substitution/displacement failure partition, and the observation that this partition is driven by a model's *output grammar* (gated vs. free-text) rather than its architecture family (CNN detector vs. transformer VLM). This is a nontrivial, somewhat counterintuitive finding, well supported by the controlled ablations (prompt paraphrase sweep, IoU threshold sweep) showing gated models stay omission-dominated regardless of prompt/threshold while free-text models never emit omissions regardless of prompt/threshold.
- **Claimed vs. supported**: the claim "VLMs can be as vulnerable as detectors" is supported reasonably well by Table 1/2 (cASR ranges overlap substantially between families, 9.2–57.7% for VLMs vs 18.2–78.3% for detectors). But this is based on only 5 VLMs and 6 detectors, all under a single white-box suppression attack and a single person-detection task — "as vulnerable" is an empirical observation on this specific benchmark, not a general law.
- **Claimed vs. supported — the "more dangerous" framing**: the distribution-shift finding (gated VLMs that failed by omission in-distribution shift to failing by displacement/substitution on Waymo) is a real, specific, well-documented pattern in the data (e.g., InternVL3-2B's omission share collapsing from 98.3% to near-zero). This is probably the paper's most novel and policy-relevant result, but it rests on evaluating distribution shift via one OOD dataset (Waymo street scenes) — generalizing "VLMs become more dangerous under distribution shift" from one shift type is a stretch beyond what's directly shown.
- Useful secondary finding: raising the IoU threshold τ mainly inflates failure for free-text (always-emit) models, since omission-dominated models already fail maximally regardless of τ — a clean mechanistic confirmation of the gating theory via ablation (Appendix A.2).
- Useful secondary finding: prompt phrasing substantially changes raw cASR magnitude (e.g., MiniCPM-V 4.6 ranges 9.2%–42.7% across four paraphrases) but does *not* change the qualitative failure-mode pattern (gated stays omission-dominated, free-text stays near-zero omission) — supports the robustness of the mechanistic claim even though absolute numbers are prompt-sensitive.

## Caveats — stated and inferred

- **Digital-only evaluation, not physical** (stated): the authors explicitly say patches are "digitally simulated" and never printed or captured by a camera; "physical" refers to the threat model (printability/pose-robustness constraints), not the evaluation medium. No real-world transfer is measured.
- **White-box only** (stated): all attacks assume full gradient access to the target model, which the authors acknowledge "does not reflect real-world deployment scenarios." Black-box/transfer attacks are left to future work.
- **Single attack objective** (stated): only a suppression objective is tested; the authors note future work should check whether the failure-mode partition holds under different attack objectives (e.g., targeted misclassification).
- **Single task, single class** (inferred): the entire benchmark is restricted to single-person images with a "person" query — a very narrow slice of the open-vocabulary grounding capability VLMs are marketed for. Results may not generalize to multi-object scenes, occluded/multiple-person images, or other object categories.
- **Small model pool, no error bars/statistical testing** (inferred): only 5 VLMs and 6 detectors are tested, each with one trained patch; there's no reported variance across multiple patch-training seeds, so claims like "VLMs can be as vulnerable as detectors" rest on point estimates from a handful of models rather than a distribution.
- **OOD generalization claims rest on one shift type** (inferred): the "under distribution shift, failure modes become more dangerous" conclusion is drawn from a single OOD dataset (Waymo driving footage) against patches that were never trained on or exposed to that domain; it's unclear whether this pattern holds for other distribution shifts (lighting, pose, camera angle, different patch placement) or is specific to the COCO/VOC→Waymo gap.
- **Manual filtering introduces potential selection effects** (inferred): datasets were filtered down to single-person images and manually curated to remove "extra unannotated people" and night-time Waymo images — reasonable for controlled comparison, but the resulting "kept" fractions are small (8–21% of original pools for COCO/VOC/Waymo), so it's worth asking whether the retained subset is representative of real deployment imagery.
- **No comparison to non-attacked, task-equivalent confidence thresholds for VLMs** (inferred): detectors are evaluated at conventionally "operated" confidence thresholds (0.5 / 0.3), chosen by convention rather than per-model-tuned optimal operating points; it's not fully addressed in the paper whether different (non-conventional) detector threshold choices would change the family-level comparison, though the confidence-threshold ablation (Appendix A.4) partially addresses this by showing cASR trends across thresholds.
- **No funding/COI issues flagged** (stated): authors disclose no external funding; nothing else of note here.
- Not addressed in the paper: real-world print/camera transfer rate, robustness to common post-processing (e.g., compression, motion blur) beyond the EOT distribution used in training, and behavior on multi-person/cluttered scenes.
