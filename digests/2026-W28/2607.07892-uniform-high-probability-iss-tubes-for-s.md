# Uniform High-Probability ISS Tubes for Sampled-Data State Estimation

**Authors:** Jerzy Baranowski

**arXiv:** [2607.07892](https://arxiv.org/abs/2607.07892)

**Categories:** eess.SY

**Submitted:** 2026-07-08

**Relevance:** 7/10 — matched: Delay-compensated perception for mobile robots

---

## TL;DR
This paper builds a way to compute finite-horizon "tubes" (uncertainty envelopes over an entire time interval, not just at one instant) around continuous-time observer estimates that are only corrected using sampled-and-held sensor measurements. It formally separates process noise, sampled measurement noise, and "staleness" from holding an old measurement, and shows how to co-design the observer gain and metric to minimize worst-case tube width. On a linear compartment benchmark and a nonlinear flexible-joint benchmark, jointly optimizing the observer for tube width shrinks the worst-case error bound by 31% and 22.4×, respectively.

## First-principles breakdown

**The problem.** In many monitoring/control systems (chemical plants, robots, embedded sensors), a physical state evolves continuously but is only measured at discrete sampling instants. An observer (a virtual estimator, like a Kalman filter or Luenberger observer) is run to reconstruct the state continuously from these intermittent, noisy measurements. The question this paper asks is: how do you get a rigorous bound on the estimation error that holds *simultaneously for every instant* in a time window, not just at the sampling instants themselves? This matters for alarms/safety checks: you need to know the state couldn't have wandered outside a safe region at *any* point since the last update, not just that it was probably fine at the last check.

**Why this is hard / what's different from a Kalman filter.** A standard Kalman filter or covariance band gives you a *pointwise* statement: "at time t, the error is within X with 95% probability." But stacking many such pointwise guarantees across a whole trajectory does not give you a simultaneous guarantee over the whole interval — the probability of *all* of them holding jointly can be much lower than each individual one (analogous to why "each coin flip is fair" doesn't bound the probability that a long sequence never deviates). The paper's core trick is to instead make ONE probability statement about the disturbance/noise magnitude over the entire horizon (a "disturbance envelope" — e.g., "with probability ≥1−δ, the noise never exceeds level d̄ anywhere in [0,T]"), then push that single event through a deterministic stability inequality to get simultaneous containment for the whole trajectory. This sidesteps the union-bound-over-time problem entirely.

**The mechanism, step by step:**
1. **Input-to-state stability (ISS)** is a standard control-theory concept (Sontag): it says the state of a system driven by some disturbance input stays bounded by a function of the initial condition (decaying with time) plus a function of the disturbance's magnitude. Here it's applied to the *estimation error* dynamics, not the plant itself.
2. **Assumption 1 (deterministic ISS bound)**: error at time t is bounded by a decaying term from initial error, plus a term scaling with the worst-case disturbance seen so far.
3. **Assumption 2 (finite-horizon disturbance envelope)**: over the fixed window [0,T], the disturbance's sup-norm stays below some deterministic value with probability ≥1−δ.
4. **Theorem 1**: combining these two gives — with probability ≥1−δ — the error stays inside a computable time-varying bound r(τ;T,δ) for *every* τ in [0,T] simultaneously. This is the key "lifting" step: one horizon-level probabilistic event about the input implies a whole-trajectory deterministic guarantee about the error.
5. **Quadratic Lyapunov specialization**: to make this computable, they assume a quadratic energy function V(e)=eᵀPe decays exponentially except for disturbance forcing (a standard "dissipation inequality," provable via LMIs — linear matrix inequalities, a standard convex-optimization tool in control). This yields concrete ellipsoidal tubes (eᵀPe ≤ ρ(t)) and, by projecting the ellipsoid onto each coordinate, componentwise interval tubes (|eᵢ(t)| ≤ rᵢ(t)).
6. **Sampled-data specialization**: they explicitly model three separate error-driving channels: (a) process disturbance w(t), (b) sampled measurement noise v_k, and (c) "held-output mismatch" ζ_h(t) — the error from acting on an old sample while the true output has since moved on. This last term is bounded using a Lipschitz/velocity argument (Lemma 9): the output can't change faster than the state's velocity times the Lipschitz constant, so mismatch grows with sampling interval length.
7. **Observer co-design**: since the observer gain L affects all three channels differently (bigger L fights nominal error faster but amplifies noise and staleness), they set up a semidefinite program (LMI-based convex optimization) that jointly picks the gain L and the Lyapunov metric P to minimize the *worst normalized componentwise tube half-width* across all channels and states, subject to the tube satisfying the ISS/dissipation constraints. This is done for a fixed decay rate a, then swept over a grid of a values (Algorithm 1).
8. **Nonlinear extension**: for systems with a known, structured nonlinearity (e.g., torque-like term with known location/argument), they use an S-procedure-based LMI (a standard robust-control technique for turning a bounded nonlinearity constraint into an extra convex constraint) that avoids treating the nonlinearity as an arbitrary Lipschitz full-state term — this keeps the design less conservative.

**Validation approach.** Two benchmarks: (1) a 3-state linear "compartment" model (nonnegative masses flowing between compartments) under both bounded noise and a contaminated-Gaussian-mixture noise regime; (2) a nonlinear flexible-joint robot model. They compare the ISS tube's simultaneous-containment behavior against Kalman filter, EKF, Gaussian MHE, and Huber (robust) MHE bands, which only offer pointwise/local uncertainty via covariance or inverse-Hessian (Laplace) approximations.

## Key insights

- **Genuinely new conceptual contribution**: the explicit "horizon-level disturbance event → simultaneous whole-trajectory error containment" lifting (Theorem 1) is a clean, general way to convert local ISS stability results into interval-valid probabilistic tubes, cleanly avoiding a union-bound-over-time blowup. This is the paper's central theoretical device.
- **Practically useful modeling contribution**: explicitly decomposing the sampled-data observer error into three separate channels (process noise, sampled measurement noise, held-output staleness) and showing staleness is a *design-relevant, non-negligible* channel — in the linear benchmark, the staleness contribution (0.0396) was actually larger than the process-noise contribution (0.0346). This supports treating sampling period as a first-class tunable in observer design, not just an implementation afterthought.
- **The co-design payoff is the paper's headline empirical result**: jointly optimizing gain + metric for tube width (rather than just for nominal contraction/convergence speed) meaningfully shrinks and rebalances the worst-case tube — 31% reduction in the linear case, 22.4× in the nonlinear flexible-joint case. The evidence supports this specific numeric claim only within the two constructed benchmarks under the stated disturbance envelopes — it is a demonstration that the design procedure *can* produce large improvements, not a general theorem about how much improvement to expect.
- **Distinguishing claimed vs. supported**: the paper explicitly frames the ISS tube as a "robustness-oriented monitoring bound alongside statistical estimator uncertainty," not a replacement for Kalman/MHE — this framing is honest and is supported by their own comparison showing Kalman/MHE bands are much narrower under nominal Gaussian noise (i.e., the ISS tube is deliberately more conservative in exchange for a stronger, whole-trajectory guarantee).

## Caveats — stated and inferred

- **Finite-horizon and envelope-conditional guarantees only** (stated): all guarantees are conditional on the assumed disturbance envelope holding; the paper does not address structural model error outside the aggregated disturbance channels.
- **Nonlinear result is "regional," not global** (stated): the flexible-joint guarantee depends on a calibrated output-rate bound (M_y) valid only on a prescribed operating region; the authors explicitly say empirical stress-testing (500 random + 195 structured trajectories with zero violations) supports but does not prove this bound holds globally.
- **Conservative envelope construction admitted** (stated): the R2 (contaminated-measurement) regime uses a "worst-scale Gaussian-mixture tail bound and union bound," which the authors say is visibly conservative relative to pointwise stochastic intervals; they suggest "dependence-aware extreme-value bounds" as future work to tighten this.
- **MHE uncertainty comparator is a local approximation with a known flaw** (stated): the Laplace/inverse-Hessian covariance approximation for MHE doesn't account for active positivity constraints truncating the true posterior, so it's flagged as a "local uncertainty diagnostic" rather than a rigorous comparator.
- **All evaluation is simulation-only** (inferred): both benchmarks are simulated (linear compartment model and flexible-joint model), with no real sensor/hardware data or embedded-timing experiments; the authors themselves list "experimental deployment, embedded timing assessment... remain outside the present study" as future work (stated as a limitation).
- **Perfect initialization assumption in the simulation** (stated): "all estimators start from the true initial state" — a favorable, somewhat unrealistic protocol choice that is not what the tube design's initial-error set (radius 0.1) actually assumes; this could make trajectory-level performance look better than it would with realistic initialization error.
- **Single fixed decay-rate grid search, not joint global optimization** (inferred): the LMI co-design is solved for a discretized grid of decay rates 'a' with the best chosen post hoc (Algorithm 1) rather than jointly optimized in one convex problem — this is a heuristic outer loop, and the paper doesn't report sensitivity to the grid's coarseness beyond the appendix sweeps for other hyperparameters.
- **No comparison against alternative guaranteed-estimation baselines** (inferred): despite extensively citing set-membership, ellipsoidal, and interval-observer literature as related work, the numerical study only compares against stochastic estimators (KF/EKF/MHE variants), not against these other deterministic/guaranteed-bound competitor methods that arguably answer a similar "guaranteed containment" question.
- **Sensitivity analyses are one-at-a-time, not joint** (stated in Appendix A.4): the authors explicitly caveat that their sensitivity sweeps (sampling interval, scale, M_y, initial radius) vary one quantity at a time and "should not be interpreted as a joint robustness analysis."
- **Single-author paper with AI-assisted writing** (stated): the manuscript used ChatGPT for language/structural review, and there is one author — not itself a methodological flaw, but relevant context for independent replication/scrutiny; only self-verification (reconstructing LMI residuals independently) is reported, with no independent/external replication mentioned.
