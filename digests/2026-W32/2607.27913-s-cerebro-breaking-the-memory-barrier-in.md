# S-CEReBrO: Breaking the Memory Barrier in Continuous EEG Monitoring

**Authors:** Glenn Anta Bucagu, Thorir Mar Ingolfsson, Yawei Li, Luca Benini

**arXiv:** [2607.27913](https://arxiv.org/abs/2607.27913)

**Categories:** cs.LG

**Submitted:** 2026-07-30

**Relevance:** 9/10 — matched: LLM inference efficiency and long-context serving

## TL;DR
S-CEReBrO is an EEG foundation model that replaces standard Transformer attention with "Windowed Alternating Attention," restricting each attention computation to a small local neighborhood in time and space so the KV cache stays constant size regardless of recording length. This lets it process EEG streams up to 14 hours long (100x longer than full attention, 3x longer than low-rank linear attention) while using less memory and running faster. Despite having only 2.4M parameters, it matches or beats larger foundation models on 7 of 11 EEG downstream tasks.

## First-principles breakdown

**The problem.** EEG data is a 2D signal: C channels (electrodes) × T timesteps. Channel count is small and fixed (2–64), but for continuous monitoring (e.g., wearable seizure detection), T grows without bound. Transformer-based foundation models process EEG by tokenizing it into patches and running self-attention over all tokens. Standard self-attention computes interactions between every pair of tokens, and to do so it must keep a "key-value (KV) cache" — the internal representations of all past tokens — resident in memory. As T grows, this cache grows too, eventually overflowing the memory of any real device (or even a GPU). This is the "memory barrier" the title refers to: it's not that the model can't compute the answer, it's that it can't afford to hold enough historical state to keep computing as the stream continues indefinitely.

**Why prior fixes fall short.** Several EEG foundation models tried to cut the O((CT)²) cost of full attention (LaBraM): BIOT uses low-rank linear attention approximations (O(CT) compute), CBraMod and LUNA restructure attention across channels/time (O(T(C+T))), and the authors' own prior model CEReBrO uses "alternating attention" — splitting attention into separate spatial (cross-channel) and temporal (cross-time) layers to reduce compute to O(CT(C+T)). The catch: all of these still use *global* attention within their respective dimension — every token can still attend to every other token across the entire recording — so their resident memory footprint still scales with O(T). Cheaper compute doesn't fix the fundamental problem: as long as attention is global, you must keep all past KV states around, so memory grows without bound during continuous monitoring.

**This paper's mechanism.** S-CEReBrO's key move is enforcing "algorithmic locality": instead of each token attending to all other tokens, Windowed Temporal Attention (WTA) restricts each token to attend only to a fixed-size local neighborhood of nearby timesteps (window size w_t, default 5), and Windowed Spatial Attention (WSA) restricts each token to a fixed-size local neighborhood of channels (window size w_s, default 7). Because the window is fixed size, once a token slides out of the active window it can be evicted from the computational buffer (FIFO-style, like a sliding buffer) — the model never needs to hold KV states for the whole history, just for the current window. This makes peak memory O(1) instead of O(T).

The obvious worry: doesn't restricting attention to local windows lose long-range information? The paper addresses this two ways. First, layer-specific dilation and shift factors (e.g., look at positions 1, 2, or 4 steps away, staggered per layer) let different layers cover different, offset slices of the signal, so the effective receptive field expands with network depth even though each individual layer's window is small (this mirrors dilated-convolution tricks and Longformer-style sliding window attention from NLP, which the authors explicitly cite as their inspiration but distinguish because EEG is a 2D, non-linear-grammar signal unlike 1D text). Second, alternating WTA and WSA layers means that even though a temporal window can't see far-away timesteps directly, the spatial layers mix channel information at each timestep, and information from evicted temporal tokens has already been "smeared" into the channel-mixed representation and propagates forward through depth — so it isn't simply gone, it's compressed and passed on rather than kept verbatim.

Architecturally, the model tokenizes each channel via a sliding window (patch) into a latent embedding, adds temporal position embeddings and 3D-electrode-coordinate-derived spatial embeddings, then passes through N=3 pairs of alternating WSA/WTA blocks with MLPs. Pre-training uses masked autoencoding (MAE): random patches are masked, the model reconstructs them, loss is a weighted sum over masked and visible patch reconstruction error — standard self-supervised recipe, nothing novel here, just applied to this backbone.

## Key insights

- **Genuinely new**: the windowing + eviction scheme applied to alternating spatial/temporal attention specifically for EEG, yielding the first EEG foundation model with claimed O(1) peak memory relative to signal duration (Table 1's comparison across BIOT/CBraMod/LaBraM/LUNA/CEReBrO backs this up architecturally — all others are O(T) peak memory by the authors' own analysis of their algorithms, not just empirical measurement).
- **Evidence-supported efficiency claim**: scaling experiments (Fig. 2, on an A100) show windowed attention processes signals up to 50,000s (~14h) without OOM, versus much shorter limits for full/alternating/linear attention, and beats linear attention on memory (55%) and throughput (2.1x) at T=15,000s. This is a real empirical measurement, not just asymptotic complexity argument.
- **Accuracy claim is more mixed than the headline suggests**: "SoTA on 7 of 11 tasks" is true per Table 4, but the margins are inconsistent — on some tasks (Mumtaz, Mental Arithmetic) S-CEReBrO is notably worse than BIOT/CBraMod, and gains on won tasks are sometimes small relative to standard deviations across seeds (e.g., TUAB 89.30±0.25 vs CBraMod 89.36±0.46 — actually a loss, consistent with "7 of 11" not 8). The claimed insight "global attention is often redundant for EEG" is supported directionally but not universally — the model loses on 4/11 benchmarks including some clinically important ones (TUAB abnormal classification, ISRUC sleep staging, Mumtaz, Mental Arithmetic).
- **Parameter efficiency** (2.4M vs. 3.2–369M for baselines) while remaining competitive is a real and useful practical contribution for embedded/wearable deployment, which is the paper's stated target use case.

## Caveats — stated and inferred

- **Pre-rebuttal/unpublished status** — stated: this is explicitly "the pre-rebuttal version of a paper accepted at MICCAI 2026," meaning it hasn't been through final peer review revisions.
- **No long-duration downstream evaluation** — stated (as future work): the scaling analysis (Fig. 2) only measures memory/latency/throughput on synthetic long inputs, not actual task accuracy on hour-scale continuous recordings. The paper itself says "future work will focus on developing long-form benchmarks to evaluate hour-scale streaming" — meaning the core motivating claim (this enables *useful* continuous monitoring) is untested on real downstream performance at long durations; only efficiency, not accuracy, is validated at scale.
- **Mixed downstream results downplayed in framing** — inferred: the abstract/conclusion foreground "SoTA on 7 of 11 tasks" and "60% fewer parameters," but 4 of 11 benchmarks show the model losing to prior smaller/foundation baselines, including clinically significant tasks like TUAB and sleep staging (ISRUC). The paper does not discuss why these losses occur or what the windowed locality bias costs on those specific tasks.
- **Comparisons restricted to <10M-parameter foundation models** — stated: "we restrict our EEG foundation model baselines to the highest performing models with fewer than 10M parameters" for "practical deployability." This is a reasonable framing choice but also inferred to be a boundary that excludes larger LaBraM variants (up to 369M params per Table 1) that might outperform S-CEReBrO outright — the paper doesn't report those comparisons.
- **No ablation on window size / dilation / shift hyperparameters** — inferred: Table 2 lists specific chosen values (w_s=min(C,7), w_t=min(T,5), dilation {1,2,4}, shifts {0,1,-1,2,-2}) but the paper presents no ablation study showing how sensitive performance is to these choices, so it's unclear if these are well-justified or tuned/cherry-picked for the reported benchmarks.
- **Single hardware target for scaling claims** — inferred: the memory/throughput scaling analysis is run only on "an NVIDIA A100 GPU with 40GB RAM," not on the resource-constrained/wearable hardware that motivates the paper; conclusions about deployability on real wearable devices are extrapolated, not directly measured.
- **Small variance across only 5 seeds** — stated implicitly via reported std devs — for several tasks the S-CEReBrO improvement over the next-best model is within or close to one standard deviation (e.g., TUAB, ISRUC, SHU-MI), which weakens confidence in "SoTA" claims for those specific tasks despite being labeled as wins or losses in Table 4.
- **Data leakage control is only partial** — stated: "subjects from the TUAB dataset are strictly excluded" from pretraining, but no equivalent statement is made about excluding subjects from the other 10 downstream benchmark datasets from the pretraining corpus, leaving potential overlap for other benchmarks unaddressed in the paper.
