# CSCWD: Cross-Scale Channel-wise Knowledge Distillation for Lightweight Tiny Object Detection on Edge Devices

**Authors:** Amir Zamani, Zeinab Ghasemi-Naraghi

**arXiv:** [2609.30395](https://arxiv.org/abs/2609.30395)

**Categories:** cs.CV

**Submitted:** 2026-09-24

**Relevance:** 9/10 — matched: Onboard object detection from a moving UAV

---

## TL;DR
This paper distills a heavier YOLO11m-P2 "teacher" (which has a high-resolution detection branch for tiny objects) into a compact YOLO11n "student" by matching the teacher's high-resolution P2 features to the student's coarser P3 features, rather than only matching same-resolution layers as prior distillation methods do. On aerial drone-detection benchmarks, the distilled student (YOLO11n-CSCWD) gains ~3 points mAP@0.5 over a matched baseline with zero added inference cost, running at 12.15 FPS on a Raspberry Pi 5. The core claim is that *where* (which scale) the supervision comes from matters more than the distillation loss function itself.

## First-principles breakdown

**The problem.** Detecting tiny objects (e.g., small drones in aerial video) is hard because the object occupies very few pixels, so there's little spatial/appearance signal to detect it from. Standard lightweight detectors like YOLO11n compress the image through a "feature pyramid" — a stack of feature maps at shrinking resolutions (P3, P4, P5, roughly 1/8, 1/16, 1/32 of the input resolution). By the time you reach even the shallowest level the model uses (P3), a lot of fine spatial detail about tiny objects is already gone. You could fix this by adding a higher-resolution P2 branch (1/4 resolution) to the detector, but that adds real compute/memory cost at inference time — bad for edge devices like a Raspberry Pi.

**Knowledge distillation (KD), the general idea.** Train a small "student" network to mimic internal representations of a larger, more capable "teacher" network during training. After training, discard the teacher; the student keeps its original (cheap) architecture but has learned to produce more informative internal features. This gets some of the teacher's power without any of its runtime cost.

**Channel-wise Distillation (CWD), the specific prior method.** Rather than forcing the student's raw feature values to match the teacher's (as in earlier "FitNets"-style regression), CWD normalizes each feature channel into a spatial probability distribution (a softmax over spatial locations, with a temperature parameter T controlling how peaked it is) and minimizes KL-divergence between teacher and student distributions per channel. This teaches the student *where in the image* each channel should focus attention, not just the exact activation values — considered better suited to dense prediction tasks like detection.

**Why prior work falls short here.** Conventional feature distillation matches teacher and student layers of the *same* spatial resolution (e.g., teacher P4 ↔ student P4). But a lightweight student like YOLO11n has no P2-equivalent layer at all — its shallowest level is P3. So the teacher's most spatially detailed, most tiny-object-relevant representation (P2) simply has nowhere to transfer to under same-scale matching. Prior "scale-aware" work (ScaleKD) addresses scale mismatch generally but the authors position their P2→P3 case as a specific, more direct instance of this problem.

**This paper's mechanism (CSCWD).** During training only:
1. Train a "teacher" — YOLO11m with an added high-resolution P2 detection branch — on the target domain.
2. Train the student (YOLO11n, standard architecture, no P2) normally, then add distillation losses:
   - Cross-scale: student's P3 features are aligned to teacher's P2 features (the novel part).
   - Same-scale: student's P4↔teacher P4, and P5↔teacher P5 (conventional CWD, kept for the deeper layers).
3. Alignment mechanics: since channel counts differ, a learnable 1×1 convolution projects student features into the teacher's channel dimension. Since P3 (student) and P2 (teacher) are also at different spatial resolutions, the projected student feature is bilinearly upsampled to match the teacher's resolution.
4. Once aligned, both apply the CWD channel-wise-softmax + KL-divergence loss (Eq. 8-9) and sum across the three pyramid levels (Eq. 10), added to the normal YOLO detection loss (Eq. 11).
5. After training, the teacher, the projection layers, and all distillation machinery are thrown away. The deployed model is a bog-standard YOLO11n with the exact same parameter count and inference graph as before — it has just learned better internal features during training.

**Evaluation setup.** Trained/evaluated on Drone-vs-Bird (aerial drone footage, standard "seven-sequence" validation split), then tested zero-shot (no fine-tuning) on a different dataset, DUT-Anti-UAV, to check generalization. Also physically deployed on a Raspberry Pi 5 using NCNN (a mobile-inference framework) at FP16 precision to measure real latency/throughput/memory.

## Key insights

- **Novel contribution (claimed and reasonably supported):** cross-scale distillation (teacher-P2 → student-P3) outperforms same-scale distillation using the *same* enhanced teacher by 2.09 mAP@0.5 points (50.17% vs 48.08%), while both use the identical teacher and student architectures. This isolates the effect to *which scale pairing* is used, not just "having a better teacher" — a fairly clean ablation.
- **Teacher capacity alone doesn't explain the gain:** using a teacher without P2 (plain YOLO11m) at same-scale CWD gives only 44.08% — much worse than the P2-teacher cross-scale result. This supports the "spatial source matters" claim.
- **Deployment cost is genuinely unchanged:** because teacher and auxiliary modules are discarded post-training, the student's parameter count (2.58M), FLOPs, latency (~82ms), and memory footprint on real Raspberry Pi hardware are essentially identical to the non-distilled baseline. This is a real, measured (not just claimed) result — a rarer thing in KD papers that often only report FLOPs, not measured on-device latency.
- **Recall vs. precision trade-off, and honest nuance in ablations:** the paper explicitly reports that a different distillation loss (MGD) actually beats CSCWD on mAP@0.5 (50.53% vs 50.17%) and mAP@0.5:0.95, while CSCWD only wins on Recall. The authors themselves conclude "the 0.36-point difference does not support a claim of universal CWD superiority" — the real contribution is the cross-scale pairing, not the specific loss function. This is a good-faith caveat rather than cherry-picking.
- **Zero-shot cross-dataset generalization:** improvement transfers to DUT-Anti-UAV without fine-tuning (48.29%→50.06% mAP@0.5), though the stricter mAP@0.5:0.95 metric is essentially flat (24.04 vs 24.00), meaning the gain is mostly in detection sensitivity/confidence, not tighter localization — the authors state this explicitly.
- A secondary diagnostic metric (nTCR, "normalized Target Concentration Ratio") shows the student's features are statistically more concentrated on target regions post-distillation (p<0.001), but the authors are careful to note this is correlational and doesn't always track final detection accuracy (e.g., one sequence, GoPro 002, has higher nTCR but *lower* mAP).

## Caveats — stated and inferred

- **Single-domain evaluation** — the entire study is UAV/aerial drone detection; the authors state generalization to "broader tiny-object benchmarks" beyond this domain is future work. (stated)
- **One decreasing sequence unexplained** — GoPro 002 sequence shows a mAP drop from 28.86%→23.48% with CSCWD versus baseline, described only as "scenario-dependent behavior" without a causal explanation. (stated)
- **Loss-function superiority not established** — CSCWD's own distillation loss (CWD) is outperformed by MGD on two of four metrics in their own ablation; the paper concedes it cannot claim CWD is the best possible loss, only that the cross-scale pairing is the key contribution. (stated)
- **nTCR is correlational, not causal** — authors explicitly say it does not establish that feature concentration causes better detection. (stated)
- **Thermal/sustained-load result is a single run** — the Raspberry Pi temperature comparison is based on "one controlled 10-min run... and should not be interpreted as a statistical estimate of long-term thermal reliability." (stated)
- **Resolution non-monotonicity unexplained/unisolated** — accuracy peaks at 960×960 input and drops at 1280×1280 for both models; authors suggest train-test resolution mismatch (trained only at 640) may contribute but "the experiment does not isolate this mechanism." (stated)
- **Code not publicly available** at preprint time, and the Drone-vs-Bird dataset itself requires request-based access from challenge organizers — limits independent reproducibility. (stated, under Data/Code availability)
- **No comparison against ScaleKD directly** — the paper cites ScaleKD as the closest related cross-scale method but does not appear to run it as an empirical baseline in the tables; comparisons are only against same-scale CWD, MGD, and a hybrid loss, plus non-distillation detectors (YOLOv8n/v10n/YOLO11s). This weakens the claim of superiority specifically over prior cross-scale distillation approaches. (inferred)
- **Zero-shot generalization tested on only one external dataset** (DUT-Anti-UAV), and even there mAP@0.5:0.95 (the stricter metric) shows essentially no improvement — the headline zero-shot gain is confined to the looser IoU=0.5 metric. (inferred, though partially acknowledged by authors as a "qualification")
- **Literature-reported baselines in Table 2 use different data splits/protocols** and are explicitly flagged by the authors as "contextual references rather than direct rankings" — meaning some of the more impressive-looking comparisons (e.g., 75.7% from Wong et al.) are not apples-to-apples and shouldn't be read as this method being competitive with them. (stated)
- **Ablation training budget/epochs for alternative losses (MGD, hybrid) not detailed** in the excerpted text — unclear if MGD and the hybrid variant received equivalent hyperparameter tuning to CSCWD, which could bias the "0.36 point" comparison. (inferred — not addressed in the paper)
- **Preprint status** — this is an arXiv preprint (Sept 2026), not yet peer-reviewed; no venue/acceptance mentioned for this specific paper (a related companion paper by overlapping authors is noted as accepted at ICEE, but not this one). (inferred)
