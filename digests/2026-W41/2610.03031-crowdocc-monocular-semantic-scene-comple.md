# CrowdOcc: Monocular Semantic Scene Completion for Quadruped Robots in Crowded Indoor Environments

**Authors:** Feiyang Chen, Jincheng Hu, Yiduo Chen, Jihao Li, Yue Liang, Bingzhao Gao, Yanjun Huang, Yuanjian Zhang

**arXiv:** [2610.03031](https://arxiv.org/abs/2610.03031)

**Categories:** cs.CV, cs.RO

**Submitted:** 2026-10-02

**Relevance:** 7/10 — matched: Metric and temporally-consistent monocular depth

---

## TL;DR
CrowdOcc introduces an RGB-D dataset (25.1K frames, 11 indoor scenes) and a monocular semantic scene completion (SSC) model purpose-built for quadruped robots in crowded indoor spaces, where humans occlude static structures and are themselves hard to reconstruct accurately. The model adds two modules — Normal-Guided Scene Geometry Fusion (NGSGF) for occlusion-robust geometry and Human-Centric Sparse Interaction (HCSI) for better human occupancy placement — on top of an existing depth-lifting SSC pipeline (ISO). On CrowdOcc's scene-disjoint test set it reports state-of-the-art results (15.80 IoU, 11.40 mIoU, 46.23 Human IoU), beating prior baselines by small margins.

## First-principles breakdown

**The underlying task — Semantic Scene Completion (SSC):** Given limited sensor input (here, a single RGB image), predict a dense 3D voxel grid labeling each voxel as empty or as one of several semantic classes (floor, wall, human, door, etc.). This is useful for robot navigation/planning: the robot needs to "fill in" occluded or unseen parts of a scene (e.g., infer that a wall continues behind a person) to build a usable 3D map.

**Why monocular (single RGB camera)?** LiDAR/depth sensors are heavier, pricier, and less common on small robots. Using just a color image is cheaper but much harder since depth/geometry must be inferred, not measured.

**Standard pipeline (MonoScene, VoxFormer, ISO, etc.):** Extract 2D image features → "lift" them into 3D voxel space using estimated depth (depth tells you how far each pixel's feature should be placed in 3D) → run a 3D encoder/decoder to densify/complete the sparse voxel occupancy and classify semantics. ISO, the closest prior work, improves this lifting using depth-aware feature projection.

**Why these pipelines fail in crowded indoor scenes:** Two problems the authors identify:
1. *Occluded static geometry*: when people stand in front of walls/floors, the depth-based lifting has little information about what's behind them, since depth cues alone say "there's a person here" but don't constrain the orientation/continuity of the hidden wall surface.
2. *Human occupancy is unreliable*: a person's silhouette in the image is foreground and easily confused with background, so existing models reconstruct humans incompletely or place them in the wrong 3D location.

**No existing dataset fits this setting** — existing SSC datasets are either static indoor (no crowds), driving-scene outdoor, or synthetic, and none combine a low quadruped-eye viewpoint with real, dense human presence and dynamic human occupancy labels (Table I).

**Dataset construction (CrowdOcc):** They solve the "how do you even get ground-truth labels for humans moving and occluding things" problem by splitting into two branches:
- *Static branch*: use only human-free frames, aggregate point clouds over many frames (since static things don't move, multi-frame fusion fills in gaps), then transfer 2D semantic masks (from Grounded SAM 2, a vision foundation model) onto this dense 3D reconstruction. This gives clean, dense static-scene semantics without human contamination.
- *Dynamic branch*: humans change pose/shape frame to frame, so you *can't* aggregate multiple frames for them (that would blur/smear the geometry). Instead, extract the human mask+points from a single current frame, align it into the static scene's coordinate frame, refine its exact placement using the synchronized depth map, and mask out areas where there isn't enough 3D evidence (rather than guessing).

This static/dynamic decoupling is the dataset's core methodological trick — it's why they can get good human labels despite non-rigid, fast-changing geometry that can't be aggregated like a static wall can.

**NGSGF (geometry fix):** Normal problem: depth tells you distance to a point, but not the local surface orientation. A wall behind a person and a wall hit edge-on give similar depth gradients near occlusion boundaries but very different surface normals. The authors use a frozen pretrained depth+normal estimator (MoGe-2) to get surface normal predictions per pixel, encode them (with a validity mask to ignore unreliable normal estimates), and fuse this "normal feature" with the image feature via a windowed (local, not global) attention mechanism — essentially, for each small image patch, let geometry (normal) information refine/correct the raw image feature before it gets lifted into 3D. This is added as a residual (original feature + learned-scaled correction), which is a common trick to let the network start from the safe baseline and only add corrections it has learned are useful.

**HCSI (human-occupancy fix):** Rather than treating all 3D voxels equally, a lightweight "Human-Routing" sub-network scores every voxel for "is this part of a human," then keeps only the top-K most confident candidates (after non-max suppression to avoid redundant nearby picks) — a sparsity trick to focus compute only where humans likely are. These candidate voxels then do self-attention with each other (modeling human-human relations, e.g. multiple people near each other) and cross-attention with their local 3D neighborhood (modeling human-scene context, e.g. a person near a door). The refined features are written back only into those selected voxel locations (others untouched) — again a residual update. This targets the "humans are incomplete/misplaced" failure mode directly, rather than treating all voxels uniformly like generic 3D encoders do.

**Training:** Standard scene-completion + depth auxiliary losses (inherited from ISO) plus a dedicated BCE+Dice loss supervising the human-routing scores, so the network learns to pick human candidates correctly, not just semantic classification.

## Key insights

- **Genuinely new**: the CrowdOcc dataset itself — real quadruped-eye-view, crowded indoor RGB-D data with carefully constructed static/dynamic-decoupled occupancy labels. This fills a real gap (Table I shows no prior dataset combines low viewpoint + real crowding + dynamic human labels), and is arguably the paper's most durable contribution regardless of the model's performance.
- **Claimed novel mechanism**: using surface normals (via a frozen off-the-shelf model, MoGe-2) as a complementary geometric cue to depth for occlusion-robust lifting (NGSGF), and a sparse, human-routed local/global attention scheme (HCSI) to specifically fix human occupancy completeness/placement.
- **What the evidence actually supports**: the ablation (Table III) shows cumulative, modest, monotonic improvements: swapping depth prior to MoGe-2 (+0.40 IoU/+0.53 mIoU but Human IoU *drops* slightly, 43.79→42.88), adding HCSI (+0.45 IoU, Human IoU +2.89), adding NGSGF (+0.46 IoU, Human IoU +0.46). So HCSI is the component driving most of the human-occupancy gain; NGSGF's isolated contribution to Human IoU is small, and its main claimed benefit (better wall/static geometry) is argued more from qualitative figures and class-wise IoU (wall 9.88→11.80) than large aggregate numbers.
- Overall gains over the strongest baseline are modest in absolute terms (+1.31 IoU, +0.68 mIoU, +2.11–2.44 Human IoU) — real but incremental, not a dramatic leap.

## Caveats — stated and inferred

- **Dataset scale is small** — 11 scenes total (8 train/val, 3 test), 25.1K frames. Cross-scene generalization is evaluated on only 3 held-out physical scenes. (inferred — small scene count limits how confidently "generalization to unseen indoor scenes" can be claimed; the paper does not discuss scene diversity, room types, or statistical variance across scenes.)
- **Semantic label noise/manual refinement**: semantic labels come from a vision foundation model (Grounded SAM 2) projected into 3D and then "manually refined" — the extent and consistency of manual refinement, inter-annotator agreement, or error rates are not quantified. (stated process, but reliability not addressed in the paper.)
- **Human label construction relies on heuristics**: "uncertain" human regions are excluded from supervision rather than labeled, and validity masking removes "geometrically invalid or ignored voxels" — this could systematically exclude the hardest occlusion cases from both training and evaluation, inflating apparent performance on human occupancy. (inferred.)
- **Absolute performance is still low**: IoU of 15.80 and mIoU of 11.40 are quite low in absolute terms (even the best class, human, is only 46.23 IoU) — the paper presents this as SOTA relative to baselines, but doesn't discuss how far this is from being practically usable for navigation/planning. (inferred — no discussion of downstream task utility or failure-mode severity.)
- **Baselines not purpose-built for this setting**: comparison methods (MonoScene, NDC-Scene, ISO, EmbodiedOcc, SplatSSC, GPOcc) are general-purpose monocular SSC models not designed for human-crowded scenes; none appear tuned or adapted specifically for this dataset beyond standard retraining. The paper doesn't address whether these baselines were given equal hyperparameter tuning effort. (inferred.)
- **MoGe-2 dependency**: both the depth prior and surface normals used by NGSGF come from a frozen, off-the-shelf pretrained model (MoGe-2). Performance and generalization are thus partly inherited from this external model's quality on indoor/crowded scenes, which is not independently evaluated. (inferred.)
- **No discussion of real-time/onboard feasibility**: despite motivating the work with onboard quadruped perception, there's no reported inference speed, latency, or compute budget analysis for deployment on a robot. (inferred — stated motivation about "onboard perception" is not followed up with runtime numbers.)
- **Ablation isolates only 3 additive components over one baseline (ISO)**: no ablation on window size for NGSGF's local attention, choice of K in HCSI's top-K selection, or sensitivity to the normal-validity mask threshold. (inferred — missing ablation depth.)
- **Single train/test split, no cross-validation or multiple seeds reported**: only one scene-disjoint split is used; variance across different scene splits isn't reported, so the magnitude of the claimed gains (often ~0.4–2 points) could be within noise. (inferred.)
